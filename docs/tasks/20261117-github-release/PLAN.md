# 计划

目标：为现有本地视频学习项目准备可发布的 GitHub 资料。范围：仓库名称与描述、Topics、README、示例截图、许可证、发布前敏感数据检查。非目标：创建 GitHub 仓库、提交或推送、上传用户视频和数据库、修改核心业务功能。

顺序：盘点功能与风险 -> 整理资料和防护 -> 生成合成截图 -> 独立审核 -> 修复与验证。停止条件：资料与代码一致，敏感数据不进入待发布文件，截图来自合成数据；或外部发布权限阻塞。

计划审核：通过。第一阶段仅准备本地资产；第二阶段用户提供已克隆仓库及 GitHub 地址，范围扩展为同步、验证、提交和推送。原仓库许可证优先，保留 Apache-2.0。
